# Armando Cardona Lara — Developer Portfolio

Professional portfolio for Armando Cardona Lara, presenting verified web and
software projects, technical skills, continuing education, and contact channels.

## Stack

- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS v4
- Motion for restrained, reduced-motion-aware reveals
- next-themes for light and dark themes
- Vercel for production hosting and Git-based deployment

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

Project content is maintained in `src/lib/projects.ts`. Screenshots in
`public/images/projects/` are genuine captures of the listed live projects.
